Il nostro web service è disponibile per tutti i progetti della classe:

💻 Esempio di integrazione per i compagni

I compagni possono integrare il nostro servizio con questo semplice codice:


// JavaScript per chiamare il nostro API
async function getExerciseSuggestion() {
    const response = await fetch('http://[NOSTRO-IP]:3000/api/exercise-suggestion?age=16&level=beginner');
    const data = await response.json();
    console.log(data.data.exercise); // "Squat"
    console.log(data.data.repetitions); // "3x12"
    return data;
}
